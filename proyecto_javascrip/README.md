## 🎯 Descripción
Este proyecto muestra una ficha interactiva que presenta información detallada sobre un sistema de monitoreo agrícola avanzado, incluyendo sensores, estadísticas y datos generales del cultivo.

Incluye interactividad como cambio de tema, copia al portapapeles y manejo dinámico de datos usando ES2023.
